
# QueryPal – Smart Customer Support Chatbot

QueryPal is a smart customer support chatbot developed as a university senior project. It helps users get answers to their questions through AI-generated responses and provides additional customer support features.

## Features
- User registration and login.
- AI-generated answers to user questions.
- Conversation history.
- File and voice input.
- Customer support ticket creation.
- Admin monitoring and management.

## Technologies Used
- React.js
- Node.js
- Express.js
- MySQL
- Python
- Ollama – Llama 3.2 1B
- REST APIs
- JWT Authentication

## Project Structure
- `frontend/` – React.js application.
- `backend/` – Node.js and Express.js server.
- `ai-service/` – Python AI service.
